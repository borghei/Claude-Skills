# Weekly Publishing Plan

One sheet per week. Copy the slots from the `plan_builder.py` output, then add
the angle and the status by hand. Fix the angle only for the week about to
start; later weeks keep pillar, format and ask and get their angle on the day
they are planned.

Angle rule: the line names what happened, not what the post is "about".
"The week the planning software was down and the paper board took over" is an
angle. "Resilience in operations" is not.

## Pre-week checklist

- [ ] Every `error` flag resolved by changing the config and rebuilding
- [ ] Every `warn` flag has a written decision above
- [ ] No more than one promotional post this week
- [ ] Each slot has a source entry or a named plan to get one
- [ ] Naming checked for every entry used: clear, or consent obtained, or anonymised
- [ ] Nothing in this week touches a no-go subject
- [ ] Time set aside on each posting day to answer replies
- [ ] Conversation blocks are in the diary
