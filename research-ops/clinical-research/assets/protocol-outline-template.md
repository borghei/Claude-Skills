## Pre-submission checklist

- [ ] All 15 sections completed or explicitly deferred to a named agreement
- [ ] Exactly one primary endpoint, with all four defining attributes
- [ ] Estimand defined including intercurrent event handling
- [ ] Eligibility criteria justified; none stated twice; all verifiable
- [ ] Withdrawal from treatment and from study defined separately
- [ ] All four analysis populations defined; ITT primary
- [ ] Missing data strategy and sensitivity analysis pre-specified
- [ ] Sample size justified with every input and its source
- [ ] Interim analyses have spending function and boundaries, or none planned
- [ ] SAE reporting window within 24 hours
- [ ] Stopping rules for harm and futility defined
- [ ] Schedule of assessments matches the CRF field by field
- [ ] Registration prepared for submission before first enrolment
- [ ] Biostatistics sign-off obtained
- [ ] Clinical sign-off obtained
- [ ] Regulatory affairs sign-off obtained
