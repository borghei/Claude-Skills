# Disclosure Label Templates

Copy, fill the brackets, and paste into your creative brief or CMS. One block per asset. Keep the filled record with the asset — it is your evidence file.

---

## 1. Asset disclosure record

```
Asset ID:                [id from content manifest]
Asset title:             [title]
Channel / placement:     [e.g. YouTube in-stream, TikTok in-feed, website hero]
Audience regions:        [EU / US / US-NY / UK / IN]
AI involvement:          [none | assistive | partial | generated]  Tool(s): [names + versions]
Realistic?               [yes/no]   Real people depicted? [yes/no]   Synthetic performer? [yes/no]
Legal disclosures:       [e.g. EU Art. 50(4) deepfake label; NY synthetic performer]
Platform disclosures:    [e.g. YouTube altered/synthetic toggle; TikTok AIGC toggle]
Endorsement disclosure:  [none | wording used]
Label text used:         "[exact text]"
Label placement:         [corner tag top-left, 3 s | end card | caption first line | spoken at 0:02]
Screenshot of label:     [link]
Screenshot of toggle:    [link]
Checker run:             disclosure_checker.py exit [0/2] on [date]
Approved by:             [name, role, date]
```

## 2. Visual corner tag (video / image)

```
┌──────────────────────────────────────┐
│ [AI-generated]                       │   ← top-left or top-right, never under platform UI
│                                      │     min. text height ≈ 4% of frame height
│                                      │     contrast ratio ≥ 4.5:1 against background
│                                      │     visible from first frame for ≥ 3 s,
│                                      │     or persistent for deepfakes of people
└──────────────────────────────────────┘
```

Variants: `AI-generated` · `AI-altered` · `AI performer` · `AI image` · `AI voice`

## 3. End card (artistic / satirical exception, long-form video)

```
This film was created with AI tools.
Characters and scenes are fictional.
[Brand] · [year]
```

## 4. Text byline (public-interest article)

With editorial control:
```
Written with AI assistance. Reviewed and edited by [Name], [Role], who is responsible for this article.
```
Without editorial control:
```
This article was generated by AI.
```

## 5. Chatbot opener

```
Hi, I'm [Brand]'s AI assistant — not a person. I can make mistakes.
Type "agent" at any time to reach a human.
```

## 6. Influencer brief clause

```
Disclosure (mandatory, non-negotiable):
- Start the caption with "Ad" or "Paid partnership with [Brand]" (first line, before "more").
- Say it out loud in the first 5 seconds of any video.
- Use the platform's paid-partnership tool IN ADDITION to the above, not instead.
- If any AI-generated or AI-altered visuals, voice or avatar are used, add "AI-generated" on screen
  and tick the platform's AI-content toggle.
- Do not claim personal use of the product unless you have actually used it.
Posts that miss any of these will be taken down and not paid.
```

## 7. Review-programme incentive notice (to reviewers)

```
Thanks for trying [product]. We'd value your honest review — positive or negative.
Your [discount/free product] does not depend on what you write.
Please mention that you received [incentive] in your review.
```
